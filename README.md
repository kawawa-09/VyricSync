# VyricSync

VOCALOIDシーケンスファイルから、MMDリップモーションファイルを生成します

## 概要

> このソフトでは
 > - Dear ImGuiによる強力なGUI
 > - 精巧な設定により、更なる複雑なリップ
 > - ボーカルのみWAV(PCM)により、F0を解析し、Dynamix、Pitchを取得し、反映ができる
 > - MMDモデルで、設定を簡単に反映しながら、スムーズにプレビューへ移行
 > - ピアノロールにより、手軽にVOCALOIDシーケンスファイルを確認できる
